กลุ่มเรียน 1.2-1

เหตุผลที่อยากเรียน Full stack web developmentเนื่องจากสนใจในด้านการพัฒนาเว็บไซต์ทั้งหมด ตั้งแต่ฝั่ง client ไปจนถึงฝั่ง server


ความคาดหวังต่อวิชานี้ คือ ได้เรียนรู้ทักษะที่จำเป็นในการพัฒนาเว็บไซต์อย่างครบถ้วน และสามารถนำไปประยุกต์ใช้ในงานจริงได้


อะไรจุดอ่อน ที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา เนื่องจากยังไม่มีประสบการณ์มากพอในด้านนี้และยังไม่เคยเรียนรู้จึงไม่เข้าใจเนื้อหาบางช่วง
